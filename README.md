## 📖 About

This is my personal portfolio site — built to showcase hands-on work in **offensive security, SOC/Blue Team operations, and cloud infrastructure security**, done through labs, coursework, and self-directed projects.

I'm currently studying **Cybersecurity (Test d'intrusion, SOC Analyste)** at Cité des Métiers et des Compétences Tamesna, Morocco, with practical experience across pentesting, threat detection, and Active Directory / cloud environments.

## 🚀 Getting Started

Clone the repo and open `index.html` directly — no build step required.

```bash
git clone https://github.com/Anonymous25-25/ffpp.git
cd ffpp
open index.html   # or just double-click it
```

## ☁️ Deployment (Vercel)

This is a static site — `index.html`, `styles.css`, `script.js`, and the `images/` folder must all sit **at the repository root**. In your Vercel project settings, leave **Root Directory** empty/default (`./`) unless you restructure the repo into a subfolder.
